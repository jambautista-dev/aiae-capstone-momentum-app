# Slalom Brand Standards

Apply these to any UI work in this project — new components, edits, or additions — without needing to be told each time.

## Colors
- Primary action color: Slalom Blue `#0C62FB` (hover/pressed: Slalom Dark Blue `#002FAF`)
- Single secondary accent: Coral Red `#FF4D5F` — this is the ONLY secondary brand color used in this app. Never introduce Cyan, Purple, or Chartreuse.
- Backgrounds: White `#FFFFFF` (primary), Light Gray `#E6E6E6` (cards/panels)
- Text: Black `#000000` (primary), Dark Gray `#666666` (secondary/muted)
- Rule: Slalom Blue must be visually present in every screen, not just an incidental icon.

## Typography
- Primary font stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` (stand-in for the licensed Slalom Sans font, which isn't available in this project — flag if real Slalom Sans web font files become available)
- Supporting serif: `'Lora', Georgia, serif` (Slalom's approved secondary typeface, loaded via Google Fonts)
- Never use Avenir Next LT Pro — reserved exclusively for PowerPoint templates
- Sentence case everywhere; no all-caps except short "eyebrow" labels
- Text is always flush-left, ragged-right — never centered or justified
- Max 3 type sizes per screen
- Line-height: ~1.1 for body copy, ~0.90 for headlines

## When adding new UI
Check new components against this file before finishing — don't wait to be asked to "apply branding."
